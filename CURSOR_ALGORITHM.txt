│ SOLUTION: Intelligent offset mapping accounting for inserted characters    │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ EXAMPLE: User types "12345" → Visual shows "$12,345"                       │

Original Text:  1  2  3  4  5
Position:       0  1  2  3  4  5
                ↓  ↓  ↓  ↓  ↓  ↓
Visual Text:    $  1  2  ,  3  4  5
Position:       0  1  2  3  4  5  6  7

┌─────────────────────────────────────────────────────────────────────────────┐
│ ALGORITHM 1: originalToTransformed(offset)                                  │
│ Maps original cursor position → visual position                            │
└─────────────────────────────────────────────────────────────────────────────┘

Input: offset = 3 (cursor after "123" in original)
       originalText = "12345"

Step 1: Get substring before cursor
        beforeCursor = "123"

Step 2: Count commas that would be inserted
        formatted = DecimalFormat("#,###").format(123) = "123"
        commasBeforeCursor = 0

Step 3: Calculate visual position
        visualPos = 1 ($) + 3 (offset) + 0 (commas) = 4
        
Result: Cursor at position 4 in "$12,345" (after "2")

┌─────────────────────────────────────────────────────────────────────────────┐
│ ALGORITHM 2: transformedToOriginal(offset)                                  │
│ Maps visual cursor position → original position                            │
└─────────────────────────────────────────────────────────────────────────────┘

Input: offset = 4 (cursor after "2" in visual "$12,345")
       newTextString = "$12,345"

Step 1: Get visual substring before cursor
        visualText = "$12,"

Step 2: Count only data characters (digits + decimal point)
        dataChars = visualText.count { it.isDigit() || it == '.' }
        dataChars = 2 (only "1" and "2")

Step 3: Clamp to original length
        originalPos = min(2, 5) = 2
        
Result: Cursor at position 2 in "12345" (after "12")

┌─────────────────────────────────────────────────────────────────────────────┐
│ EDGE CASES HANDLED                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

1. Empty Input:
   originalText = ""
   → Returns OffsetMapping.Identity (no transformation)

2. Decimal Points:
   originalText = "12345.67"
   → Only counts commas in integer part "12345"
   → Visual: "$12,345.67"

3. Large Numbers:
   originalText = "1234567"
   → Visual: "$1,234,567"
   → Correctly handles multiple comma insertions

4. Cursor at Start:
   offset = 0
   → Returns 1 (after "$" symbol)

5. Cursor at End:
   offset = originalText.length
   → Uses minOf() to prevent overflow

┌─────────────────────────────────────────────────────────────────────────────┐
│ PERFORMANCE ANALYSIS                                                        │
└─────────────────────────────────────────────────────────────────────────────┘

Time Complexity: O(n) where n = string length
- DecimalFormat.format(): O(n)
- String.count(): O(n)
- Total: O(n) per cursor movement

Space Complexity: O(n)
- Temporary strings: beforeCursor, visualText
- Formatted string: formatted

Optimization: Negligible overhead for currency amounts (typically < 20 chars)
